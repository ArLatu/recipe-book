# Recipe Book

A small recipe collection made for the ICD0028 version control homework.
Each recipe is a separate Markdown file in the `recipes/` folder.

## Recipes


- [Draniki](recipes/draniki.md) - Belarusian potato pancakes
- [Kartulisalat](recipes/kartulisalat.md) - Estonian potato salad

## Adding a recipe

1. Create a branch named `recipe/<dish-name>`.
2. Add `recipes/<dish-name>.md` with an Ingredients and an Instructions section.
3. Add a link to the list above and open a pull request.
